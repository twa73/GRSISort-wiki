# Compiled
  * **Root2Rad** <br> Accepts a .root file and converts all of the contained TH1 histograms to RadWare .spe files and the TH2 histograms to RadWare .mat files. Useful for professors.

# Scripts
  * **autoeffic.C** <br>Reads in a root file and calculates the efficiency of each HPGe Crystal based on a specific source and activity. Currently also gain matches, etc. This script is changing frequently.
