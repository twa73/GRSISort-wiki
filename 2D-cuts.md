# 2D cuts 

Two dimensional cuts can be initialized using the ```i``` key. Once a cut has been initialized, you can add it to the list of cuts using the ```c``` key, and then save all the cuts you have created using the ```s``` key.

For more information on two dimensional cuts, see also [this guide](https://gamma.triumf.ca/large-projects/GRIFFIN/documentation/GRSISortCuts.pdf/view).
