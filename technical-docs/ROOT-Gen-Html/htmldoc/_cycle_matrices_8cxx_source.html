36 //This code is an example of how to write an analysis script to analyse an analysis tree
37 //The compiled script works like this
38 //
39 // 1. Starts in the main function by finding the analysis tree, setting up input and output files
40 // 2. Calls the CycleMatrices function
41 // 3. CycleMatrices creates 1D and 2D histograms and adds them to a list
42 // 4. Some loops over event "packets" decides which histograms should be filled and fills them.
43 // 5. The list of now filled histograms is returned to the main function
44 // 6. The list is written (meaning all of the histograms are written) to the output root file
45 // 7. Papers are published, theses are granted, high-fives are made
46 //
