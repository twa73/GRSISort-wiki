1 # HILData
2 
3 This library provides the data parser and detector classes for data taken with EAGLE at the HIL (Heavy Ion Laboratory) in Warsaw.
4 The names of the classes typically start with THIL.
5 
6 The data parser is set up to process EAGLE data written in the rlmd data format.
7 
8 Two detector classes are implimented: Eagle HPGe (TEagle), Eagle Pulser (TEaglePulser).
9 In addition the hit class TPinDiodeHits exist, which is stored in TEagle::fPinDiodeHits.
10 
11 Other classes included are:
12  - File and event classes for RLMD files,
13  - THILMnemonic, which provides an enumeration for the detector systems and digitizers, and
14  - THILDetectorInformation, which only provides functions to tell whether EAGLE data is present (which should be all the time)
15 
16 For now this parser library requires the ```hil-data``` branch of GRSISort.
17 
18 ## Installation
19 
20 To compile simply call ```make``` from inside the HILData directory.
21 
22 Tested with GRSISort ```v4.0.0.3``` and ROOT ```v6.26/00```.

24 ## Cal Information
25 
26 The nomenclature of HILData is as follows:
27  - **EA** denotes the TEagle system
28  - **PD** denotes a pin diode
29  - **PU** denotes a pulser, and is based on the Generic Detector system
30 
31 All EAGLE detector hits are set to address 0x100 plus their ID, and all pin diode hits are set to address 0x200 plus their ID.
32 
33 Since each RLMD eagle event contains the complete information of that event (one or more Germanium hits, and one or more PIN diode hits), all of this information is stored in a TEagle detector.
34 The default address used for this TEagle detector is ```0x100```, and for it to be sorted correctly, the cal-file needs at least this one address to be defined:
35 
36 ```
37 EAX01XN00X {
38 Type: TEagle
39 Name: EAX01XN00X
40 Number: 0
41 Address: 0x00000100
42 TimeOffset: 0
43 Integration: 0
44 }
45 //====================================//
46 ```
