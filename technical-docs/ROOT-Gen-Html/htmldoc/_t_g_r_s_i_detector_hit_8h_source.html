23 /////////////////////////////////////////////////////////////////
24 ///
25 /// \class TGRSIDetectorHit
26 ///
27 /// This is class that contains the basic info about detector
28 /// hits:
29 /// 1. An address. The whoami for the detector. This is the value used by TChannel::GetChannel(address);
30 ///
31 /// 2. An "Energy value." What this is left the parent class, but it is going to return a double.
32 ///
33 /// 3. A Time value. This should be a time value common for detectors (derived from the timestamp)
34 /// Units matter here, I am adobting the ns as the standard.
35 ///
36 /// 4. A Position. Tvector3s are nice, they make doing geometery trival. Each hit needs one to determine
37 /// where it is in space, the actual memory of the thing will be stored here.
38 /// *** This is not actually needed here unless we start do waveform analysis to
39 /// *** better determine where the hit is.
40 ///
41 /// 5. The waveform. Since we are dealing with digital daqs, a waveform is a fairly common thing to have. It
42 /// may not always be present, put it is echoed enough that the storage for it belongs here.
43 ///
44 /////////////////////////////////////////////////////////////////
