24 /////////////////////////////////////////////////////////////////
25 ///
26 /// \class TGRSIDetectorHit
27 ///
28 /// This is class that contains the basic info about detector
29 /// hits:
30 /// 1. An address. The whoami for the detector. This is the value used by TChannel::GetChannel(address);
31 ///
32 /// 2. An "Energy value." What this is left the parent class, but it is going to return a double.
33 ///
34 /// 3. A Time value. This should be a time value common for detectors (derived from the timestamp)
35 /// Units matter here, I am adobting the ns as the standard.
36 ///
37 /// 4. A Position. Tvector3s are nice, they make doing geometery trival. Each hit needs one to determine
38 /// where it is in space, the actual memory of the thing will be stored here.
39 /// *** This is not actually needed here unless we start do waveform analysis to
40 /// *** better determine where the hit is.
41 ///
42 /// 5. The waveform. Since we are dealing with digital daqs, a waveform is a fairly common thing to have. It
43 /// may not always be present, put it is echoed enough that the storage for it belongs here.
44 ///
45 /////////////////////////////////////////////////////////////////
