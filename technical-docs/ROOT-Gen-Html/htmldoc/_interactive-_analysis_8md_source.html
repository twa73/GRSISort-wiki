5 # The GROOT library and you.
6 
7 In addition to the many libraries in TGRSIAnalysis to make analysis easier, GRSISort also takes control of some of the behind the scene functions of ROOT to make gamma-ray analysis a bit easier.
8 
9 To take advantage of these features all one has to do is start GRSISort! They are implemented when examining and natural root classes, whether the where draw from a tree, made fresh or load from a file.
10 
11  * **GlobalFunctions** <br>
12  * **ProjectionX(TH2*,low=0,high=-1)** Helper function, only passing a TH2 returns the total Projection along the x-axis. Additionally, using this function allows GROOT to remember which matrix the return total projection belongs too. This allows one to use the 'p' command (shown in TH1 commands below) to gate along the returned axis. If low/high arguments are int bin numbers are use, else axis values are used.
13  * **ProjectionY(TH2*,low=0,high=-1)** Helper function, only passing a TH2 returns the total Projection along the y-axis. Additionally, using this function allows GROOT to remember which matrix the return total projection belongs too. This allows one to use the 'p' command (shown in TH1 commands below) to gate along the returned axis. If low/high arguments are int bin numbers are use, else axis values are used.
14  * **SaveAll(cons char *Filename, Option_t *opt="recreate")** Open a file with the filename and option given. Save all objects currently managed by GRootObjectManager. After saving, returns to the original working TDirectory.
15 
16  * **GCanvas** <br> The most notable difference, is the replacement of the TCanvas with GCanvas. This replacement is done naturally - no changes from either existing ROOT scripts or GRSISort scripts are needed to take advantage of the GCanvas default behavior. As of right now, the major changes are only for 1d histograms however, however global histogram management and 2d histogram commands are on the way.

18 ## TH1 Commands
19 | Key | Action |
20 |:------|:------|
21 | | All normal root commands/interactions.|
22 | **m** | Toggle on marker mode; when on, the histogram will remember and display the last four clicks as marks on the histogram.|
23 | **p** | If the 1d hist was made using the global ProjectionX/ProjectionY; gating the original 2D matrix this histogram came from is possible by placing markers around the gate and pressing p. The gates spectra is immediately drawn. |
24 | **B** | Cycle through types of automatic background subtraction used when projecting with **p**. Current types include: No subtraction, Fraction of the total, subtract gate from the 3rd marker (gate size set to the distance between marker 1 and 2). |
25 | **b** | Set the background, how it is set depends on **B**.|
26 | **M** | Toggle off marker mode.|
27 | **n** | Remove all markers / functions drawn on the histogram.|
28 | **N** | Remove all markers and the LAST function drawn on the histogram.|
29 | **e** | Expand the x-axis range between the last two markers.|
30 | **E** | Bring up dialogue box used to set desired x-axis range.|
31 | **o** | Unzoom the entire histogram.|
32 | **Arrow Left/Right** | When zoomed in, mover the display region to the left/right by one half of the region currently displayed.|
33 | **Arrow Up/Down** | Quickly display the next histogram stored in memory, especially useful when gating to go back and forth between gates and the total projection.|
34 | **f** | Ryan D's TPeak Fit (proper skewd gaus for gamma-rays with automatic bg) with minimum output. |
35 | **F** | Ryan D's TPeak Fit (proper skewd gaus for gamma-rays with automatic bg) with full output. |
36 | **g** | Simple Gaus fit between the last to marks, displays results of the fit **RESULTS STILL NEED TO BE VERIFIED** |
37 | **G** | Gaus fit with linear background, displays results of the fit **RESULTS STILL NEED TO BE VERIFIED** |
38 | **i** | Raw integral of counts between the two markers |
39 | **I** | Background subtracted integral of counts between the two markers |
40 | **s** | Show peak values. |
41 | **S** | Remove peak values. |
42 | **l** | Make y-axis linear. |
43 | **L** | Make y-axis logarithmic. |
44 | **F10** | Print any TPeaks currently displayed on the histogram to <histname>.fits. If file already exists, the file is destroyed and recreated. |
