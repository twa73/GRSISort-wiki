3 **Error Reporting**
4 
5 To report and error on the issue tracker, please use the error reporting template provided. To Automatically fill this out, use `sh ${GRSISYS}/util/ErrorReport.sh`. This will generate a template that has many parts automatically filled out, and looks like:

35 Please add:
36 - The computer and path you used (if applicable)
37 - The output error you received
38 - The last working commit (this really really helps us)
39 - Anything you have tried to solve the problem and results from those tries
40 
41 Please use this as your first post when reporting an error on the issue tracker as it will help us save time in solving your problem.
