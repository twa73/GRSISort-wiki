TWriteQueue Class Reference
Sorting

This Class stores a map of detector pointers in a std::queue The queue is filled in TAnalysisTreeBuilder::ProcessEvent via TAnalysisTreeBuilder::FillWriteQueue. The events are taking out of the queue and written to the AnalysisTree in TAnalysisTreeBuilder::WriteAnalysisTree.
