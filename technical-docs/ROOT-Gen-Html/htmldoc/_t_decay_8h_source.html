219 ////////////////////////////////////////////////////////////////////////
220 ///
221 /// \class TDecay
222 ///
223 /// TDecay is a class for fitting halflives during nuclear decay
224 /// A TDecay consists of multiple TDecayChains, where a TDecayChain
225 /// is starts at a specific nucleus which has a population before the
226 /// decay fit takes place. This could be a nucleus with a daughter.
227 /// One TDecayChain would consist of just the daughter while the
228 /// the other decay chain would be the parent and daughter.
229 /// TDecayChains are made up of multiple TSingleDecays which holds
230 /// the nucleus specific information such as name, id, halflife and
231 /// intensity. When any of the above classes are fit to a histogram,
232 /// they use a TDecayFit. The TDecayFit is a a TF1 with extra information
233 /// such as the class that was used to create the TDecayFit. Furthermore,
234 /// the function DrawComponents() can be used to draw the activites of the
235 /// individual nuclei involved in the TDecayFit.
236 ///
237 ////////////////////////////////////////////////////////////////////////
