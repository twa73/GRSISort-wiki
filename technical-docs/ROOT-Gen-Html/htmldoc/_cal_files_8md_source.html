3 # Cal Files #
4 Calibration files (Cal Files) are the files ending in a __.cal__ extension. They are used to perform a variety of functions:
5 - Map digitizer address to Channel Number
6 - Set a mnemonic for each channel
7 - Calibrate energy
8 - Set a charge integration parameter
9 - Calibrate CFD, LED and Time
10 - Calibrate Efficiency
11 - Set a Time Offset for a channel's Timestamps (LaBr)
12 
13 Some of this information is contained in the ODB which is read out by __grsisort__ from the start of the __.mid__ file. The [[Calibration | Calibration ]] classes can be used to set these variables in TChannel and create cal files as well.
14 
15 ## Using Cal Files #
16 When a cal file is input during the MIDAS sorting stage, the calibration data is saved to the fragment tree. After this, `grsisort` defaults to reading the cal file from the fragment tree. If a different calibration is desired, `TChannel::ReadCalFile("*name_of_cal_file*")` can be called to read in a different cal file.
17 __NOTE:__ This data is not written to the tree unless `TChannel::WriteToRoot()` is called.
18 
19 Once a calibration from a cal file is active, access to the various calibrations is straight forward. For example, one can access the calibrated energy for a fragment using the `GetEnergy()` command.
20 
21 Finally, if you would like to create a new calibration file from a fragment tree you can run the command `TChannel::WriteCalFile("<calibrationfile>.cal")`.
22 
23 ## Cal File Format #
24 Calibration files are in a plain-text format that is easily modifiable. The labels are case-insensitive, but colons must be used to separate labels from values. Lines that begin with `//` are comments.
25 
26 The file is a listing of calibration parameters for individual mnemonics, like the listing below for the blue crystal in GRIFFIN clover 1:
27 ```
28 GRG01BN00A {
29 Name: GRG01BN00A
30 Number: 1
31 Address: 0x00000000
32 Digitizer:
33 EngCoeff: -0.743423 1.419230
34 Integration: 0
35 ENGChi2: 0.000000
36 EffCoeff:
37 EFFChi2: 0.000000
38 TIMECoeff: 0.000000 271.279000 -0.739159
39 TimeOffset: 0.0
40 }
41 ```
42 ``Name`` sets the mnemonic for the data from the address listed with ``Address``. If this calibration file is read in while sorting a MIDAS file to a `FragmentTree`, `Number` will be the `ChannelNumber` assigned to this address in the `FragmentTree`.
43 
44 Beyond these three primary numbers, any additional lines will set calibration values for this channel.
45 - `EngCoeff` sets the energy calibration coefficients, assuming a polynomial calibration from charge to energy. The first value is the zeroth-order coefficient (offset, set to `-0.743423` in the example above), the second is the first-order coefficient (slope, set to `1.419230` in the example above), etc.
46 - `Integration` sets the integration parameter that is used in the energy calibration.
47 - `TIMECoeff` or `Walk` sets the coefficients for the low-energy walk correction of the form t<sub>diff</sub> = a<sub>0</sub>+a<sub>1</sub>E<sup>a<sub>2</sub></sup>. In the example above, a<sub>0</sub> is 0, a<sub>1</sub> is 271.279, and a<sub>2</sub> is -0.739159.
48 - `TimeOffset` is an offset to be removed from the time stamp from the hit. Useful for TAC's. The returned value is Timestamp - TimeOffset.
49 
50 Other possible calibration parameters include:
51 - `Number`
52 - `Stream`
53 - `Digitizer`
54 - `EngChi2`
55 - `CFDChi2`
56 - `LEDChi2`
57 - `TimeChi2`
58 - `EffChi2`
59 - `LEDCoeff`
60 - `CFDCoeff`
61 - `EffCoeff`
62 - `FileInt`
