5 GRSISort calibrations are read from *cal files*. These are the files with the **.cal** extension. Various calibration classes are used to set calibration parameters. These classes are called `TCal`s and currently include:
6 - [[TGainMatch | Gain-Matching]] for gain-matching
7 - TTimeCal for time calibrations such as [[ LED Walk | LED-Walk ]]
8 
9 # TCalManager
10 A Calibration Manager is used to make doing multiple channel calibrations easier. A `TCalManager` can be filled with one type of calibration class (TCal) at any time. To create a calibration manager use:
11 ```c++
12 TCalManager *myCalManager = new TCalManager;
13 ```
14 You can get the type of TCal in the TCalManager using
15 ```c++
16 myCalManager->GetClass();
17 ```
18 Note: you can not put two different types of TCal's in the TCalManager at the same time. To put a different type of TCal in the TCalManager you must first `Clear()` the TCalManager. You can put a calibration in the cal manager by using
19 ```c++
20 myCalManager->AddToManager(myCal);
21 ```
22 where `myCal` is a pointer to the calibration being added to the manager. It should be noted that a *deep copy* of the calibration is made and the cal manager appropriately handles it's copy. If the channel for the calibration has not been set yet, it can be set while being added to the calibration manager using
23 ```c++
24 myCalManager->AddToManager(myCal,channel_number);
25 ```
26 and to overwrite the TCal at a given channel, you must use the option `"overwrite"`. For example,
27 ```c++
28 myCalManager->AddToManager(myCal,channel_number,"overwrite");
29 ```
30 To access the calibration for a specific channel in the TCalManager you can use
31 ```c++
32 myCalManager->GetCal(channel_number);
33 ```
34 and to write the set of calibrations to `TChannel` call
35 ```c++
36 myCalManager->WriteToChannel();
37 ```
