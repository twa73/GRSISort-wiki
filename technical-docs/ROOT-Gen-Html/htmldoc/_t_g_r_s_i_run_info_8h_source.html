9 ///
10 /// \class TGRSIRunInfo
11 ///
12 /// This Class is designed to store and run dependent
13 /// information. It is used to store run numbers, existence of
14 /// detector systems, reconstruction windows, etc. The
15 /// TGRSIRunInfo is written alongside both the fragment and
16 /// analysis trees.
17 ///
18 /// TGRSIRunInfo designed to be made as the FragmentTree
19 /// is created. Right now, it simple remembers the run and
20 /// subrunnumber and sets which systems are present in the odb.
21 /// This information will be used when automatically creating the
22 /// AnalysisTree to know which detector branches to create and fill.
23 ///
24 /// Due to some root quarkiness, I have done something a bit strange.
25 /// The info is written ok at the end of the fragment tree process.
26 /// After reading the TGRSIRunInfo object from a TFile, the static function
27 ///
28 /// TGRSIRunInfo::ReadInfoFromFile(ptr_to_runinfo);
29 ///
30 /// must be called for any of the functions here to work.
31 ///
32 /// Live example:
33 ///
34 /// \code
35 /// root [1] TGRSIRunInfo *info = (TGRSIRunInfo*)_file0->Get("TGRSIRunInfo")
36 /// root [2] TGRSIRunInfo::ReadInfoFromFile(info);
37 /// root [3] info->Print()
38 /// TGRSIRunInfo Status:
39 /// RunNumber: 29038
40 /// SubRunNumber: 000
41 /// TIGRESS: true
42 /// SHARC: true
43 /// GRIFFIN: false
44 /// SCEPTAR: false
45 /// =====================
46 /// root [4]
47 /// \endcode
48 ///
49 /// \author P.C. Bender, <pcbend@gmail.com>
50 /////////////////////////////////////////////////////////////////
