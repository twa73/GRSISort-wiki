17 ## Step 1: Install git
18 
19 To Install git, go to [GitHub](http://github.com) and click on *Download*.

22 ```````
23 sudo apt-get install git

28 ## Step 2: Install ROOT
29 *Already have ROOT? Proceed to [Download GRSISort](#step3)*
30 
31 Before installing root make sure you have the [required and optional packages](http://root.cern.ch/drupal/content/build-prerequisites) installed. In particular, make sure you have a copy of GSL. For use of the [MathMore](https://root.cern.ch/mathmore-library), ROOT recommends GSL 1.8 or above, but some features have been observed to work with GSL 1.13. To identify your GSL version, type
32 ```
33 gsl-config --version
34 ```
35 in your terminal.
36 
37 Go to the [root webpage](https://root.cern.ch/downloading-root), select the version you want (we recommend using a production version), and follow the instructions to download root.
38 
39 Follow the [instructions to build root](https://root.cern.ch/building-root).
40 
41 Finally, in your ./bashrc or ./profile, include the line
42 ```bash
43 source /path/to/root/bin/thisroot.sh
44 ```
45 The current supported versions of root are the stable 6er versions (e.g. 6.08.06). Root 5 is no longer supported. You might be able to run the code with v5.34.36, but we won't be able to guarantee that nor help with problems. Here are some [problems](Troubleshooting#rootproblems) that we have found at this stage.

49 ## Step 3: Download GRSISort
50 
51 Verify that your root installation has the required features enabled. Check that the output of
52 ```
53 root-config --features
54 ```
55 contains cxx11, mathmore, python, and xml.
56 
57 The newest version of GRSISort currently resides on GRIFFIN collaboration github repository.
58 
59 To Clone (Download) the newest version of GRSISort, navigate to the directory where you want the GRSISort directory to be. Clone the repo using:
60 ``````````
61 git clone https://github.com/GRIFFINCollaboration/GRSISort.git
62 ``````````
63 
64 GRSISort should now download to **./GRSISort**
65 
66 Enter into the **GRSISort** directory with `cd GRSISort`.
67 
68 To see a list of GRSISort versions available for download, use `git tag -l`.
69 The current *stable* release will be tagged under `current`.
70 The most up to date version will be tagged under `master`, see [releases](https://github.com/GRIFFINCollaboration/GRSISort/releases) for details.
71 
72 To download a the version named <version>:
73 ```
74 git checkout <version>
75 ```
76 
77 *Don't like git? (You should) The newest version can also be downloaded from [[here|https://github.com/pcbend/GRSISort/tarball/master]]*.
78 
79 If you want to contribute to the code, you need to have your own copy of GRSISort in your github account. To do this go to the GRSISort repository of the GRIFFINCollaboration and click "fork" in the top right. Now run
80 ```
81 git remote set-url origin ssh://git@github.com/<UserName>/GRSISort.git
82 git remote add upstream https://github.com/GRIFFINCollaboration/GRSISort.git
83 ```
84 where <UserName> is your own user name on github.com.
85 
86 To verify this worked, you can run
87 ```
88 git remote -v
89 ```
90 which should give you this output (again with <UserName> replaced by your own user name on github.com):
91 ```
92 origin ssh://git@github.com/<UserName>/GRSISort.git (fetch)
93 origin ssh://git@github.com/<UserName>/GRSISort.git (push)
94 upstream https://github.com/GRIFFINCollaboration/GRSISort.git (fetch)
95 upstream https://github.com/GRIFFINCollaboration/GRSISort.git (push)
96 ```

100 ## Step 4: Setup Environment Variables
101 The setup for GRSISort depends on the shell being used. To determine the Shell you are using execute
102 `````
103 echo $SHELL
104 `````
105 To setup GRSISort for a .sh shell (bash) execute `source thisgrsi.sh` in your terminal from the GRSISort Directory
106 
107 To avoid running this script every session, add the following to your **~/.bash_profile** or **~/.profile**
108 ```
109 source /Path/To/GRSISort/thisgrsi.sh
110 ```
111 If you're using a c-type shell use the scripts with .csh extension instead of the .sh extension in the commands above.

115 ## Step 5: Compile GRSISort
116 To compile GRSISort type `make`. Please be patient as compilation will take a few moments. You can speed this up if you want by using `make -j` (uses all available cores) or `make -j N` where N is the number of jobs you want to run in parallel.
117 
118 - To create the HTML documentation, you can compile with `make docs`. This is NOT REQUIRED.
119 
120 If you receive an error, please consult the [Troubleshooting](troubleshooting) page.

124 ## Step 6: Download data parser and detector library
125 *Don't want to parse data? Proceed to [???](#step8)*
126 
127 In order to parse data and to understand the setup specific detector classes, an additional library is needed.
128 This library has to provide the following functions:
129 - CreateFile(std::string& filename) which returns a pointer to a new raw data file and DestroyFile which takes a pointer to a raw data file and deletes it (returns void).
130 - CreateParser() which creates a new data parser object and DestroParser which takes a pointer to such a data parser object and deletes it.
131 - LibraryVersion() which returns a string containing the version number of the library.
132 - InitLibrary() which initializes e.g. the mnemonic class used in Channel.
133 
134 So far three parsing/detector libraries have been written:
135 
136 - GRSIData for GRIFFIN/TIGRESS experiments (https://github.com/GRIFFINCollaboration/GRSIData)
137 - ILLData for FIPPS data from ILL (https://github.com/UoG-Nuclear-Physics-Group/ILLData)
138 - iThembaData for data from the tape station at iThemba (https://github.com/UoG-Nuclear-Physics-Group/iThembaData)
139 
140 Any of those three libraries can be downloaded in the same manner as GRSISort using ```git clone <url>```.
141 This can be done anywhere, but is probably best done from within the GRSISort directory.

145 ## Step 7: Compile and use library
146 
147 In order to compile the library please follow the instructions of the library you chose to download.
148 Multiple libraries can be installed in parallel.
149 To use a library you can either provide the location of the libraries .so file on the command line, or edit .grsirc to include a line
150 ```
151 GRSI.ParserLibrary: <path to library, e.g. $(GRSISYS)/GRSIData/lib/libGRSIData.so>
152 ```
