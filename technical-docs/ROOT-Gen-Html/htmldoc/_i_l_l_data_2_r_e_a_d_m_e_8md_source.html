1 # ILLData
2 
3 This library provides the data parser and detector classes for data taken with FIPPS at the ILL.
4 The names of the classes typically start with TILL.
5 
6 The data parser is set up to process FIPPS data written in the lst data format.
7 
8 The only detector class implemented is TFipps (and TFippsHit).
9 
10 Other classes included are:
11  - the file and event classes for LST files,
12  - the TILLMnemonic class which provides an enumeration for the detector systems and digitizers,
13  - the TILLDetectorInformation which only provides functions to tell whether FIPPS data is present (which should be all the time), and
14  - the TILLDetectorHit, which implemements the algorithm for how to get the time in nanoseconds from the timestamp and CFD information.
