18 ///
19 /// \class TChannel
20 ///
21 /// The TChannel is designed to hold all non-essential
22 /// information of a TFragment (name, energy coeff, etc..)
23 /// that would otherwise clog up the FragmentTree. The TChannel class
24 /// contains a static map to every channel make retrieval fairly
25 /// easy. The TChannel class also contains the ability to
26 /// read and write a custom calibration file to set or
27 /// save the TChannel information. Most of the information is read out
28 /// of the ODB information in the MIDAS file.
29 ///
