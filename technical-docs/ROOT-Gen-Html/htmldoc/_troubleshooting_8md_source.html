25 ### Installing under OSX
26 
27 For Mac OS X you need to have greadlink and gfind installed. They can be installed using mac ports (https://www.macports.org) via ```port install coreutils findutils```, or using home brew (https://brew.sh) using ```brew install coreutils findutils```.

33 ### HTML
34 - If you receive the error `sh: 1: dot: not found` it is because you do not have a **dot** writing program. This is not really an issue, but to avoid this, install a dot program like **graphviz**. (On Ubuntu `sudo apt-get install graphviz`)

39 #### freetype
40 - You may receive the error in **asfont.c** that **freetype/freetype.h** does not exist. This can be solved by changing *line 67* in **asfont.c** from
41 ````c++
42 CODE: SELECT ALL
43 #include <freetype/freetype.h>
44 ````
45 to
46 ````c++
47 CODE: SELECT ALL
48 #include <freetype.h>
49 ````
50 
51 #### Standard C Libraries
52 - If you receive the errors:
53 ```bash
54 Error: cannot open file "gnu/stubs.h" /usr/include/features.h:399:
55 Error: cannot open file "bits/wchar.h" /usr/include/stdint.h:27:
56 Error: cannot open file "bits/wordsize.h" /usr/include/stdint.h:28:
57 ```
58 You're missing the 32 bit libc dev package:
59 
60 On **Ubuntu** it's called `libc6-dev-i386` - do `sudo apt-get install libc6-dev-i386`. See below for extra instructions for Ubuntu 12.04.
61 
62 On **Red Hat** distros, the package name is `glibc-devel.i686`
63 
64 On **CentOS 5.8**, the package name is `glibc-devel.i386`
65 
66 On **CentOS 6 / 7**, the package name is `glibc-devel.i686`.
67 
68 On **SLES** it's called `glibc-devel-32bit` - do `zypper in glibc-devel-32bit`
69 
70 Are you using Ubuntu 12.04? There is a known problem that puts the files in a non standard location. You'll also need to do:
71 ```bash
72 export LIBRARY_PATH=/usr/lib/$(gcc -print-multiarch)
73 export C_INCLUDE_PATH=/usr/include/$(gcc -print-multiarch)
74 export CPLUS_INCLUDE_PATH=/usr/include/$(gcc -print-multiarch)
75 ```
76 
77 If you encounter the problem:
78 ```bash
79 .... /usr/bin/ld: cannot find -lstdc++ ....
80 ```
81 
82 On **Ubuntu** you will need to do `sudo apt-get install g++-multilib`
83 
84 On **CentOS 5** you will need to do `yum install libstdc++-devel.i386`
85 
86 On **CentOS 6** you will need to do `yum install libstdc++-devel.i686`
87 
88 #### XML
