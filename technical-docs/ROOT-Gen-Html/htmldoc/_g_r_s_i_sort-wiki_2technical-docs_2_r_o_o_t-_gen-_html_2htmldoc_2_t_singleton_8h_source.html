22 /// This class is intended as a base class for singletons,
23 /// especially those that are written to file.
24 /// The Get() function is written such that it reads the class
25 /// from file if needed. This is the case if it hasn't been
26 /// read yet, or if the gDirectory has been changed.

28 /// always return the info of the current file.
