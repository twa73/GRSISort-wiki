5 TPeaks are used to fit photopeaks to a Gaussian + skewed gaussian. The background includes a step function. TPeaks inherit from TF1, which means the can be named, and can be written to TTrees and TFiles.

9 -----------------------------------------
10 How To Use
11 -----------------------------------------
12 TPeaks can be created as follows:
13 ```c++
14 TPeak *peak = new TPeak(centroid, low_range, high_range);
15 ```
16 To fit the TPeak, call:
17 ```c++
18 peak->Fit(histogram);
19 ```
20 where `histogram` is the `TH1*` attempting to be fit. You can also use the same options as when fitting a TF1. For example,
21 ```c++
22 peak->Fit(histogram,"+");
23 ```
24 to add the TPeak to the histogram.
25 
26 Once the TPeak is fitted, you can call
27 ```c++
28 peak->Print();
29 ```
30 To see the basic properties of the TPeak
31 ```
32  Name: Chan1173_1160_to_1190
33  Centroid: 1173.172270 +/- 0.005742
34  Area: 1885626.302501 +/- 1409.848616
35 ```
36 Or, to see more properties, such as the value and uncertainty in each parameter, use the option `Print("+")`.

38 ## Fitting Technique
39 One should always fit peaks using the proper statistical model. Gamma-rays are detected following a Poisson probability distribution. Therefore, when fitting a standard gamma ray spectrum, one should fit the peak using a *maximum likelihood distribution*. If background is subtracted, one is left with the difference of two Poisson distributed data sets, which is no longer a Poisson distributed data set. Thus, one would prefer to use least-squares fitting in this scenario.
40 TPeak accommodates for this using a default maximum-likelihood fitting flag. To see what the current status of the flag is use `TPeak::GetLogLikelihoodFlag();`. To set the status of the flag, use `TPeak::SetLogLikelihoodFlag(true);` to turn maximum likelihood on and `TPeak::SetLogLikelihoodFlag(false);` to turn change it to least-squares fitting. It defaults to on.

42 ## Parameters
43 The first time a TPeak is fit, the parameters are initialized based on the histogram passed to the `TPeak::Fit` function.
44 When a TPeak is created, the parameters are uninitialized. The names of the paramters are as follows:
45 
46 - "Height": The height of the unskewed gaussian
47 - "centroid": The centroid of the unskewed gaussian
48 - "sigma": The width of the unskewed gaussian
49 - "beta": The "skewedness" of the skewed gaussian
50 - "R": The relative height of the skewed gaussian
51 - "step": The size of the step function in the background
52 - "A": The constant part of the background
53 - "B": The linear part of the background
54 - "C": The quadratic part of the background
55 - "bg_offset": The offset in the background in the x direction
56 
57 To fix a particular component of the TPeak, for example, the width to 1.0, use:
58 ```c++
59 peak->FixParameter(GetParNumber("sigma"),1.00);
60 ```
61 To Release the paramater use:
62 ```c++
63 peak->ReleaseParameter(GetParNumber("sigma"));
64 ```
65 and to set the paramater to an initial value use:
66 ```c++
67 peak->SetParameter("sigma",1.00);
68 ```
69 which maintains its fixed/freeness.
