5 ## Reporting an issue
6 
7 Before reporting an issue, please check the wiki and the existing (open or closed) issues to see if you can find a solution.
8 
9 If you were unable to find a solution to your problem, please run ErrorReport.sh, copy and paste the resulting form and fill out the missing information.

11 ## Coding standards
12 
13 Coding standards promote code that is presented in a standardized format and easier to understand.
14 For GRSISort, we base our coding standards on ROOT's [coding conventions](https://root.cern.ch/coding-conventions).
15 Please adhere to these standards. Additional standards are listed below.
16 * When casting variables, please use a `static_cast`. For example, use:
17 ```
18 static_cast<Int_t> x
19 ```
20 rather than
21 ```
22 (Int_t) x
23 ```
